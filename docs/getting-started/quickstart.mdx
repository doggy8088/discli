# 快速上手

兩分鐘內完成第一則 Discord 訊息。這份指南假設你已完成 [discli 安裝](/getting-started/installation) 且已有 Discord 機器人 Token。若尚未擁有，先依 [第一個機器人](/getting-started/your-first-bot) 說明取得。

<Steps>
  <Step title="設定機器人 Token">
    儲存 Discord 機器人 Token，供 discli 進行驗證：

    ```bash
    discli config set token YOUR_BOT_TOKEN
    ```

    ```
    已設定 Token。
    ```

    此操作會將 Token 存到 `~/.discli/config.json`，只需設定一次。

    <Callout type="tip">
      你也可以在單次指令中用 `--token YOUR_BOT_TOKEN`，或設定 `DISCORD_BOT_TOKEN` 環境變數。詳情請參考[設定](/getting-started/configuration)。
    </Callout>
  </Step>

  <Step title="傳送訊息">
    向機器人可存取的頻道傳送訊息：

    ```bash
    discli message send "#general" "來自 discli 的問候！"
    ```

    ```
    已傳送訊息到 #general（ID：1234567890123456789）
    ```

    回到 Discord 伺服器確認，訊息應該會出現在該頻道。

    <Callout type="note">
      **頻道識別方式：**你可使用 `#` 開頭的頻道名稱（例如 `#general`）或使用純數字 ID（例如 `1234567890123456789`）。頻道名稱會在機器人可存取的伺服器內比對；若同名頻道出現在多個伺服器，建議改用 ID 以避免誤判。
    </Callout>
  </Step>

  <Step title="讀取訊息">
    取得頻道最近幾則訊息：

    ```bash
    discli message list "#general" --limit 5
    ```

    ```
    [2026-03-15 10:32] discli-bot: 來自 discli 的問候！
    [2026-03-15 10:30] Alice: 有人試過這個新 CLI 工具嗎？
    [2026-03-15 10:28] Bob: 早安，大家好！
    [2026-03-15 10:15] Alice: 歡迎加入伺服器！
    [2026-03-15 09:45] Bob: 嗨，大家
    ```

    輸出會列出最近訊息，採新到舊排序，並顯示時間與作者。
  </Step>

  <Step title="使用 JSON 輸出">
    加上 `--json` 旗標可取得結構化輸出，適合接到其他工具、或供 AI 代理處理：

    ```bash
    discli --json message list "#general" --limit 3
    ```

    ```json
    [
      {
        "id": "1234567890123456789",
        "author": "discli-bot",
        "author_id": "9876543210987654321",
        "content": "來自 discli 的問候！",
        "timestamp": "2026-03-15T10:32:00+00:00",
        "channel": "general",
        "channel_id": "1111111111111111111",
        "is_bot": true
      },
      {
        "id": "1234567890123456780",
        "author": "Alice",
        "author_id": "2222222222222222222",
        "content": "有人試過這個新 CLI 工具嗎？",
        "timestamp": "2026-03-15T10:30:00+00:00",
        "channel": "general",
        "channel_id": "1111111111111111111",
        "is_bot": false
      },
      {
        "id": "1234567890123456770",
        "author": "Bob",
        "author_id": "3333333333333333333",
        "content": "早安，大家好！",
        "timestamp": "2026-03-15T10:28:00+00:00",
        "channel": "general",
        "channel_id": "1111111111111111111",
        "is_bot": false
      }
    ]
    ```

    <Callout type="tip">
      `--json` 旗標可用於所有指令，且必須放在子指令前面：`discli --json message list`，而非 `discli message list --json`。
    </Callout>
  </Step>
</Steps>

## 還能做什麼？

你可以再嘗試以下指令：

```bash
# 列出機器人所在的伺服器
discli server list

# 列出伺服器中的頻道
discli channel list "My Server"

# 傳送 DM 給使用者
discli dm send @username "你好，這裡是測試訊息"

# 為訊息加上表情回應
discli reaction add "#general" MESSAGE_ID "👍"

# 搜尋訊息
discli message search "#general" "搜尋關鍵字"

# 開啟即時事件串流
discli listen
```

執行 `discli --help` 或 `discli <command> --help` 可查看全部指令與選項。
