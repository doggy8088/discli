# CLI 指令

涵蓋每個 `discli` 指令、子指令、參數與選項的完整參考。

## 全域選項

這些選項套用於所有指令，且必須在子指令前出現。

| 選項 | 環境變數 | 說明 |
|--------|---------|-------------|
| `--token TEXT` | `DISCORD_BOT_TOKEN` | Discord 機器人權杖 |
| `--json` | | 以 JSON 格式輸出 |
| `--yes`, `-y` | | 略過破壞性操作的確認提示 |
| `--profile CHOICE` | `DISCLI_PROFILE` | 覆蓋權限設定檔（`full`、`chat`、`readonly`、`moderation`） |
| `--version`, `-V` | | 顯示已安裝的 discli 版本並結束 |
| `--help` | | 顯示說明並結束 |

```bash
discli --version
# discli version 0.11.0
```

## message

傳送、列出、編輯與刪除訊息。

### message send

傳送訊息到一個頻道。

```
discli message send <channel> <text> [OPTIONS]
```


|-------------------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |
| `TEXT` | 是 | 訊息內容 |
| `--embed-title TEXT` | 否 | 嵌入標題 |
| `--embed-desc TEXT` | 否 | 嵌入描述 |
| `--embed-color HEX` | 否 | 嵌入顏色（例如 `5865F2`） |
| `--embed-footer TEXT` | 否 | 嵌入頁尾文字 |
| `--embed-image URL` | 否 | 嵌入圖片網址 |
| `--embed-thumbnail URL` | 否 | 嵌入縮圖網址 |
| `--embed-author TEXT` | 否 | 嵌入作者名稱 |
| `--embed-field TEXT` | 否 | 嵌入欄位（可重複，格式為 `Name::Value::Inline`） |
| `--file PATH` | 否 | 附加檔案（可重複） |

### message list

列出最近訊息。

```
discli message list <channel> [OPTIONS]
```

| 參數 / 選項 | 必填 | 預設 | 說明 |
|-------------------|----------|---------|-------------|
| `CHANNEL` | 是 | | 頻道名稱或 ID |
| `--limit N` | 否 | 10 | 要抓取的訊息數 |
| `--before DATE` | 否 | | 早於日期（YYYY-MM-DD 或 ISO） |
| `--after DATE` | 否 | | 晚於日期（YYYY-MM-DD 或 ISO） |

### message history

抓取頻道的歷史訊息。

```
discli message history <channel> [OPTIONS]
```

| 參數 / 選項 | 必填 | 預設 | 說明 |
|-------------------|----------|---------|-------------|
| `CHANNEL` | 是 | | 頻道名稱或 ID |
| `--days N` | 否 | | 抓取最近 N 天訊息 |
| `--hours N` | 否 | | 抓取最近 N 小時訊息 |
| `--limit N` | 否 | 不限制 | 最大抓取訊息數 |

### message get

依 ID 取得單則訊息。

```
discli message get <channel> <message_id>
```


|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |
| `MESSAGE_ID` | 是 | 訊息雪花 ID |

### message edit

編輯一則訊息。

```

```


|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |
| `MESSAGE_ID` | 是 | 訊息雪花 ID |

### message delete

刪除一則訊息。 需要確認。可加上 `--yes` 直接略過。

```


|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |

|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |

### message reply

回覆指定訊息。

```

```


|-------------------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |

| `--file PATH` | 否 | 附加檔案（可重複） |

### message search

依訊息內容搜尋。

```
discli message search <channel> <query> [OPTIONS]
```

| 參數 / 選項 | 必填 | 預設 | 說明 |
|-------------------|----------|---------|-------------|
| `CHANNEL` | 是 | | 頻道名稱或 ID |
| `QUERY` | 是 | | 搜尋字串（不分大小寫） |
| `--limit N` | 否 | 100 | 要掃描的訊息數 |
| `--author TEXT` | 否 | | 依作者名稱過濾 |
| `--before DATE` | 否 | | 早於日期（YYYY-MM-DD 或 ISO） |
| `--after DATE` | 否 | | 晚於日期（YYYY-MM-DD 或 ISO） |

## role

管理伺服器身分組。

### role list

列出伺服器身分組。預設不計算各身分組的成員數，並顯示為 `unavailable`，因為計算時必須逐一取得完整成員清單；在大型伺服器上速度較慢、容易觸發速率限制，且需要 Server Members 特權 intent。若要計算，請加上 `--with-member-counts`。

```
discli role list <server> [OPTIONS]
```


|----------|----------|-------------|
| `SERVER` | 是 | 伺服器名稱或 ID |

| 選項 | 必填 | 說明 |
|--------|----------|-------------|
| `--with-member-counts` | 否 | 計算各身分組的成員數；預設關閉 |

### role create

```

| `SERVER` | 是 | 伺服器名稱或 ID |

## poll

建立與管理投票。

### poll create

在頻道建立投票。

```
discli poll create <channel> <question> <answers...> [OPTIONS]
```

| 參數 / 選項 | 必填 | 預設 | 說明 |
|-------------------|----------|---------|-------------|
| `CHANNEL` | 是 | | 頻道名稱或 ID |
| `QUESTION` | 是 | | 投票問題 |
| `ANSWERS` | 是 | | 兩個以上投票選項（以空白分隔） |
| `--duration N` | 否 | 24 | 投票持續時間（小時） |
| `--multiple` | 否 | false | 允許多選 |
| `--emoji`, `-e` | 否 | | 每個答案對應的 emoji（依序，可重複） |

範例：

```
discli poll create #general "Favorite AI?" Claude Gemini ChatGPT
discli poll create #general "Best?" A B C -e a_emoji -e b_emoji -e c_emoji
discli poll create #general "Vote!" Yes No --multiple -e ok -e x
```

### poll results

```

```


|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |
| `MESSAGE_ID` | 是 | 投票訊息雪花 ID |

### poll end

提前結束投票。

```

```


|----------|----------|-------------|
| `CHANNEL` | 是 | 頻道名稱或 ID |

## serve

啟動持久化機器人程序並以 JSONL 進行雙向通訊。 事件會輸出到 stdout，指令從 stdin 讀取。

```
discli serve [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `--server TEXT` | 否 | | 依伺服器名稱或 ID 篩選事件 |
| `--channel TEXT` | 否 | | 依頻道名稱或 ID 篩選事件 |
| `--events TEXT` | 否 | all | 以半形逗號分隔的事件類型： `messages`, `reactions`, `members`, `edits`, `deletes`, `voice` |
| `--include-self` / `--no-include-self` | 否 | `--include-self` | 事件中包含機器人自己的訊息 |
| `--slash-commands PATH` | 否 | | JSON 檔案，定義要註冊的 slash 指令 |
| `--status CHOICE` | 否 | `online` | 機器人狀態：`online`、`idle`、`dnd`、`invisible` |
| `--activity TEXT` | 否 | | 活動類型：`playing`、`watching`、`listening`、`competing` |

## voice

加入語音頻道、使用 STT 轉寫語音、以 TTS 發言並播放音訊。 語音子命令需要安裝 `voice` 額外套件，請執行 `pip install 'discord-cli-agent[voice]'`（或 `uv sync --extra voice`）。 唯讀查詢（`voice status`、`voice where`、`voice members`）不需安裝 voice 相依。

參閱 [語音指南](/guides/voice) 取得完整流程。

### voice join

加入伺服器語音頻道。進行連線、確認與斷線，為一次性操作。

```
discli voice join CHANNEL [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `CHANNEL` | 是 | | 語音頻道名稱或 ID |
| `--server` | 否 | | 指定為單一伺服器範圍 |

### voice leave

離開目前語音頻道。

```
discli voice leave [--server NAME_OR_ID]
```

### voice speak

透過 TTS 合成文字並在目前語音頻道播放。

```
discli voice speak TEXT [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `TEXT` | 是 | | 要朗讀的文字 |
| `--server` | 否 | | 指定為單一伺服器範圍 |
| `--voice` | 否 | `default` | TTS 聲音名稱（依提供者而定） |
| `--speed` | 否 | `1.0` | 語速倍率 |

### voice play

透過 ffmpeg 在目前語音頻道播放音訊檔案或網址。

```
discli voice play SOURCE [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `SOURCE` | 是 | | 檔案路徑或 HTTP(S) 網址 |
| `--server` | 否 | | 指定為單一伺服器範圍 |
| `--volume` | 否 | `1.0` | 播放音量（0.0 – 2.0） |

### voice stop / pause / resume

控制目前播放。 這些指令都不需頻道參數，會操作該伺服器目前作用中的連線（或自動偵測唯一連線）。

```
discli voice stop   [--server NAME_OR_ID]
discli voice pause  [--server NAME_OR_ID]
discli voice resume [--server NAME_OR_ID]
```

### voice listen

監聽目前語音頻道並逐位元輸出每位發言者的最終轉寫結果。

```
discli voice listen [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `--server` | 否 | | 指定為單一伺服器範圍 |
| `--duration` | 否 | `0` | 在 N 秒後停止（`0` = 直到 Ctrl+C） |
| `--continuous` | 否 | false | 每次轉寫後維持連線 |

### voice capture

除錯輔助：將每位發言者的 48kHz 立體聲 PCM 寫入 WAV 檔，繞過 STT。 在監聽無結果時，確認機器人確實有接收到音訊。

```
discli voice capture [OPTIONS]
```

| 選項 | 必填 | 預設 | 說明 |
|--------|----------|---------|-------------|
| `--server` | 否 | | 指定為單一伺服器範圍 |
| `--duration` | 否 | `10` | 擷取秒數 |
| `--output-dir` | 否 | `~/.discli/debug-capture` | WAV 檔寫入路徑 |

### voice status

列出目前啟用的語音連線。 唯讀模式，不需要 `voice` 額外安裝。

```
discli voice status
```

### voice where

查詢使用者目前所在的語音頻道。 僅可讀。

```
discli voice where USER [--server NAME_OR_ID]
```

### voice members

列出語音頻道中的成員。 僅可讀。

```
discli voice members CHANNEL [--server NAME_OR_ID]
```
